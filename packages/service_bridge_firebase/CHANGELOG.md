## 1.0.0

- Initial release
- `FirebaseAnalyticsProvider` — Analytics event tracking and screen views
- `FirebaseCrashReporter` — Error reporting via Crashlytics
- `FirebaseRemoteConfigProvider` — Remote configuration with configurable fetch intervals
- `FirebasePushProvider` — Push notifications via Firebase Cloud Messaging
- `FirebaseLoggerProvider` — Structured logging through Crashlytics
- `FirebaseProviderBundle` — Convenience initializer for all Firebase providers
